# Video → Anki Dictation

YouTubeやNetflixの字幕と直前の音声を利用して、英語学習用の学習カードを作成するChrome拡張機能です。
学習カードは学習アプリ「Anki」に保存されます。

## 概要

動画を視聴しながら、学習したい字幕を選択すると、

- 字幕の取得
- 音声区間の切り出し
- 字幕の校閲
- 日本語訳
- 単語・熟語の抽出
- 学習カードの作成

までを一連の操作で行えるようにしています。

YouTubeとNetflixの両方に対応しています。

## 主な機能

- YouTube字幕の取得
- Netflix字幕の取得
- 字幕パネルの表示
- 選択した字幕区間の音声切り出し
- Geminiを利用した字幕校閲
- Geminiを利用した日本語翻訳
- 単語・熟語の自動抽出
- 固有名詞の補正
- ユーザー辞書による表記補正
- AnkiConnectを利用したAnkiカード作成
- 字幕と音声区間の時刻補正
- キーボードショートカットによる操作

## 使用技術

- JavaScript
- Chrome Extensions Manifest V3
- Chrome Extension API
- Gemini API
- AnkiConnect
- HTML
- CSS

## AIの使用範囲

本拡張機能は生成AIを積極的に利用し、コードについては、ほぼ全体でAIによる生成・修正支援を利用しています。
主に、機能設計、コード生成、デバッグ、既存コードの修正、エラー原因の調査、改善案の検討などにAIを利用しました。
一方で、どのような機能が必要か、実際に使用してどこに問題があるか、どのように改善したいかといった仕様や改善方針は自分で考え、動作確認を行いながら開発しました。
MLB選手能力変換アプリでは主に自分でコードを実装し、AIを学習補助として使用しています。
